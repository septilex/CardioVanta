HOW TO INSTALL
1. Extract this ZIP at the root of the CardioVanta repository (the same folder as package.json and README.md).
2. The four image files will be placed in docs/assets/readme/.
3. Keep the files in Git so GitHub can render the relative paths inside README.md.
4. In the README, use paths relative to the repository root, e.g.:
   ![CardioVanta landing page](docs/assets/readme/01-landing-hero.png)
