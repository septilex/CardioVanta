# CardioVanta Typography Reference

Purpose:
This directory contains visual reference screenshots used to study typography
for the CardioVanta frontend design system.

Expected reference categories:

1. Display / Heading References
   - large serif hero headings
   - section headings
   - bold serif headings
   - light serif headings

2. Body / UI References
   - body paragraphs
   - navigation text
   - buttons
   - labels

3. Technical Font Identification
   - Chrome DevTools "Rendered Fonts" screenshots
   - font-family information
   - PostScript names
   - font weights
   - computed typography measurements

Reference notes:

Mayo Clinic Serif Display

Confirmed visual reference:

Important:
These files are visual/design references only.
