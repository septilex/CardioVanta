## Accurate boundaries

- Feedback documents have no user identity relationship or personal clinical fields; no MongoDB embedding/reference relationship is claimed.
- Raw SQL uses Psycopg, not an ORM.
- The project has no Redis cache; HTTP cache headers are not described as Redis caching.
- The edit-token hash is not password hashing.
- The assessment has strict request validation, but no general-purpose IP rate-limiting middleware.
- A `VERCEL` environment forces the optional LLM feature unavailable. Do not enable it on Vercel until shared durable quota storage and privacy review are complete.
